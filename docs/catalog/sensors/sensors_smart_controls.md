# Otohom Sensors and Smart Controls

Sensors integrate with the Otohom app for real-time detection, history records, message notifications and whole-house intelligent linkage (a sensor event can trigger lights, alarms or other devices).

## Motion / PIR Sensor (Wi-Fi)

- App operation with real-time detection and whole-house intelligent linkage
- History record and message notification
- Battery level display in app
- Working voltage: 3V Li-ion battery
- Wi-Fi standard: 802.11 b/g/n
- Detect distance: 8m (max)
- Zigbee protocol supported

## Microwave Sensor (Zigbee)

- Working voltage: 100-240V AC, 50/60 Hz
- Detection distance: up to 7m
- Luminance measurement range: 0-1200 LUX
- Detecting angle: 360°
- Detects presence even with minimal movement (unlike PIR) — good for automated lighting

## Energy Meter — Single Phase

- Current range: 63A
- Frequency: 50-60 Hz
- Voltage: 100-290V
- Monitors home energy consumption in the Otohom app

## Energy Meter — 3 Phase

- Rated voltage: AC 60-300V
- Frequency: 50/60 Hz
- Monitors 3-phase energy consumption (larger homes, villas, commercial spaces)

## Door / Window Sensor

- Small and exquisite appearance
- Detects when doors, windows or drawers are illegally opened or moved
- 433MHz communication, low battery prompt, used with smart host
- Zigbee protocol 3.0
- Working voltage: 3V battery (Li-ion / Mercury cell type)
- Dimensions: 82 x 82 x 21mm
- Alarm active distance: 10m (open area)
- Connecting distance: 10m (max)

## IR Blaster (Infrared Remote Control)

- App control of infrared home appliances (TV, AC, speakers)
- AI voice control
- Whole-house intelligent linkage
- Compatible with multiple types and multiple brands of infrared home appliances
- Frequency type: 38K
- Power supply: DC 5V/1A
- Communication: Wi-Fi 2.4 GHz, range 8m max (open space)
- Dimensions: 65 x 65 x 20mm
- Adapter not included

## Smart Water Valve Controller

- Power: DC 5V / 1A
- Communication: Zigbee; Wi-Fi 2.4 GHz / 20m (outside / open space)
- Valve pressure: 1.6 MPa (handle valve)
- Fits valve sizes: 4, 6 point / 1, 1.25 inch
- Torque: 30-60 Kg.cm

## Smart MCB / Distribution Box Controller

- Dimensions: 89mm x 55mm x 44mm (3 MCB size)
- Power: 220V 5A (device function)
- Requirement: open-type distribution box / rack (6MS)
- Output: 500W motor or 2000W resistive load

## Water Tank Level Sensor

- Sensor: 5-channel sensor from tank to device (Cat 6 cable, not included)
- Connectivity: Wi-Fi 2.4 GHz
- Life span: 100,000 operations
